Cuteblog is a free and open source code for bloggers. Unique UI design makes your site very attractive.

### Installation 

+ Download source code cute blog project
+ Upload on your web hosting
+ Settup your blog - visit on your web project config/_config.yml edit with code editor and change site_title with your site title.
+ Content - for create update and delete content you can visit on content folder. and you can see we have many example content, now you can edit and rename files,and edit with your needs, for create new content you can create new markdown file and name it with your article, for example mypost.md , and copy paste fontformatter from example article, and create your content article - save it for update blog - for detail you can play video demo.
