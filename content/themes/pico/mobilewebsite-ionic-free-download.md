If you need to build modern website and mobile app , so use piconic website themes template is the best solutions.

Develope with markdown and work on PHP lang, make easy for you to upload on PHP hosting, like cpanel, plesk, and others.  Pico Piconic flatfile cms with markdown and YAML files for work, so you can easy to update and manage your site.


### Installation

+ Download piconic source code project. 
+ Upload and extract on your hosting website project. if you want to install it on main website so you can upload on root folder - example myweb.com, if you want install on your sub domain, so you need to create sub domain , then upload source code project on sub domain - example piconic.myweb,com , and if you want to install it on others directori, so you can create new directori and upload piconic source code project on your new directori - example myweb.com/newpiconic.
+ That's it !! Your website is live now !!
+ Next step you need to configure your site, visit on your webproject folder on your hosting.


### Settup

After you have upload piconic source code project and install on your web project, now you need to settup your site, visit on yourwebproject and open config/_config.yml - change site_title with your site title.

Now we need to configure navigation , if you want to change it so you can access on content/_meta.md open files and edit with your needed.

Then save it, for update your website configuration.

### Content Article

Piconic is work with markdown for update article. with markdown make easy and fast for update content article.

You can visit on content folder ,for create new content , just create new file and name it with yourpost for example mypost.md then open files and we need to insert this fontfromatter code: 
```
Title: insert title here
Description: Your description in here
Cover: Insert URL image cover link here
Hidden: true
Template: post 
```
Or you can open example article, we have create before , then copy all fontformatter in to your new post files, then edit with your needed.

For delete article post - just click on one article and delete it.

### Build Android App

If you want to export your website project to android application , so you can do it with use apache cordova or capacitor.

For easy and simple step , you can use android studio and create webview for export your website project in to android application.
