Let's develope modern website with python technology, [pelician](https://getpelican.com/) static site generator.

### Installation

+ create venv on pelican project and activate
+ open your pelican project folder
+ create new folder and name it `themes` in to your pelican folder,  or simply run `mkdir themes`
+ download source code pelicando or run `git clone https://github.com/mesinkasir/peliciando.git`
+ upload `peliciando` to `themes` folder
+ open `pelicanconf.py`
+ insert THEME = 'themes/peliciando' on pelicanconf.py , or open pelicanconf.py from peliciando and copy to project/pelicanconf.py
