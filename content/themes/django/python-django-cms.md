### How to

+ Download [Python](https://www.python.org/)
+ Extract Source code files in to your project folder
+ Access project folder with terminal
+ Install [Django](https://www.djangoproject.com/) run `pip install django`
+ Create VENV run `python -m venv venv`
+ Activate VENV run `venv\Scripts\activate`
+ Migration Database run `python manage.py makemigrations`
+ Insert Database in to project run `python manage.py migrate`
+ Create user run `phyton manage.py createsuperuser` or `py manage.py createsuperuser`
+ Run Project `py manage.py runserver`
+ Open `localhost:8000`
+ For login on admin area visit `localhost:8000/admin`
+ Login with your username and password
+ And now you can work with this django project.
