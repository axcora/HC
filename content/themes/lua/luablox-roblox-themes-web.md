### Chapter 1 - What Is A Static Site Generator?

A static site generator is a tool that turns your content into static HTML files.

You write content in Markdown - a simple text format. The generator turns it into HTML, CSS, and JavaScript files. Those files are your website. You upload them to any host, and your site is live.

Why static?

- No database to maintain
- No server to patch
- No backend to hack
- Hosting is often free
- Pages load as static files

LUAX PRO is a static site generator built in pure Lua. Lua is a small, fast programming language. It is often used in game development, especially Roblox with Luau. LUAX PRO uses Lua to build your site, so you only need Lua installed - nothing else heavy.

### Chapter 2 - Install Lua 5.4

Lua is the only runtime LUAX PRO needs. Installation takes less than two minutes because Lua is less than 1MB.

Step 1 - Check if Lua is already installed

Open your terminal - Command Prompt on Windows, Terminal on Mac / Linux - and type:

`lua -v`

If you see `Lua 5.4.x`, you already have Lua and can skip to Chapter 3. If you see command not found, continue below.

Step 2 - Windows Installation

Option A - Chocolatey (Recommended)
If you have [Chocolatey](https://chocolatey.org/) installed, run this in Administrator Command Prompt:
choco install lua

Option B - Manual Download
1. Go to luabinaries.sourceforge.net
2. Download the Windows x64 binary for Lua 5.4
3. Extract the ZIP file to C:\lua
4. Add C:\lua to your system PATH: Right-click This PC > Properties > Advanced system settings > Environment Variables > Under System variables, find Path, click Edit > Click New, type C:\lua, click OK
5. Close and reopen Command Prompt, then verify with lua -v

Step 3 - macOS Installation

Using Homebrew (Recommended)
Open Terminal and run:
```
brew install lua
```

If you do not have Homebrew, install it first:
```
 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
Then run brew install lua again.

Verify:
```
lua -v
```
You should see Lua 5.4.x.

Step 4 - Linux Installation

Ubuntu / Debian:
```
sudo apt update
sudo apt install lua5.4
```

Fedora / CentOS:
```
sudo dnf install lua
```

Arch Linux:
```
sudo pacman -S lua
```

Verify:
```
lua -v
```

Step 5 - If lua -v Still Fails

Your PATH is not set correctly. On Linux / Mac, find where Lua was installed:
which lua5.4

If it returns `/usr/bin/lua5.4`, create a symlink:
```
sudo ln -s /usr/bin/lua5.4 /usr/local/bin/lua
```
Then try `lua -v` again.

Full guide: https://luaxpro.axcora.com/docs/02-installation/

### Chapter 5 - Run Decap CMS Locally

`Decap CMS` is the admin panel that lets you and your clients edit content from browser, without code.

Difference:
- Controller = The page that lists things. Example: src/services.md controls the Services listing page.
- Collection item = One thing in the list. Example: src/services/luau-scripting.md is one service.

### Chapter 18 - Deploy To Cloudflare, Vercel, Or Any Static Host

[Cloudflare Pages](http://cloudflare.com/) - Recommended

Cloudflare Pages has no Lua by default. Don't use plain lua build.lua.

In Cloudflare Pages > Create Application > Pages > Import from Git:
Build command, copy this exactly:
curl -sL https://www.lua.org/ftp/lua-5.5.1.tar.gz -o /tmp/lua.tgz && tar -xzf /tmp/lua.tgz -C /tmp && cd /tmp/lua-5.5.1 && make posix && cp src/lua /tmp/lua && cd - && /tmp/lua build.lua
Build output directory: dist
Framework preset: None

Use make posix, not make generic. generic disables io.popen and build will fail.

[Vercel](https://vercel.com):
Import repo from GitHub. Config is already in vercel.json in ZIP.
Build command: lua build.lua
Output: dist

[Github Pages](https://github.com):
Rename `.github/workflows/deploy.yml.example` to `deploy.yml`
Push to main branch. Github will build and deploy dist/ automatically.

Any Other Host - AWS S3, cPanel, VPS, Firebase, Surge, Plesk:
Run luax build locally, then upload the dist/ folder contents to your host.
That's it. No server, no database needed.
For Decap CMS on these hosts, edit content locally with Decap CMS, then push / upload again.

Decap CMS in production on Cloudflare / Vercel / Github Pages: Use Decap locally for editing, not in production. Your content is still saved to your Git repo.

### Chapter 19 - Templates - LAX For Beginners

LUAX PRO uses LAX templating. Only in .lax files, never in .md files.

In .lax files:
```
@layout(default) - Use layout
@for collections.posts - Loop posts
@for collections.services - Loop services
@for collections.projects - Loop projects
@for collections.docs - Loop docs
@if author / @else / @end - Condition
@include(header) - Partial
@title, @content, @url, @date - Page variables
@metadata.title, @metadata.url - Site variables
```

Example in .lax file:
```
@layout(default)
<h1>@title</h1>
<p>@content</p>
@for collections.posts limit=3
<h2><a href="@url">@title</a></h2>
<p>@excerpt</p>
@end
```

If you write docs ABOUT LAX inside a .md file, don't write raw @ and <. Use HTML entities: &#64; for @, &lt; for <, &gt; for >. So LAX does not try to execute it as code.

For beginners: You don't need to learn LAX deeply to use LUAX PRO. Start by editing content in Decap CMS. Learn LAX only when you want to customize layouts.

### Chapter 20 - Troubleshooting - Most Common Beginner Errors

Error: lua: command not found
Fix: Install Lua 5.4 or 5.5.1 and add to PATH. Or use full path to lua binary. See Chapter 2.

Error: 'popen' not supported / io.popen error on Cloudflare
Fix: You used make generic. Use make posix in Cloudflare build command in Chapter 18.

Error: Decap CMS login fails in production
Fix: You must enable Identity + Git Gateway on Netlify. Or use Decap locally with decap-server. See Chapter 17.

Error: Site builds but images broken
Fix: Check image path in frontmatter. Images must be in public/images/ and referenced as /images/your-image.webp.

Error: Changes not showing
Fix: Run luax build again, hard refresh browser Ctrl + Shift + R, clear cache.

Error: Git push fails
Fix: Check remote URL, check you did git branch -M main, check GitHub repo is empty or you pulled first.
