### How to

+ Download Python
+ Download source code
+ Extract Source code files in to your project folder
+ Access your project folder with terminal
+ Create VENV run python -m venv venv
+ Activate VENV run venv\Scripts\activate
+ Install Flask run pip install Flask
+ Install SQL Alchemy database pip install Flask-SQLAlchemy
+ Run Project flask run
+ Open localhost:5000
+ For admin area access on localhost:5000/cutelist

### Make your flask website blog online
+ Make sure your hosting support with Python app
+ Create python app
+ Run flask installation on terminal
+ Upload source code in to python flask
+ Restart python app
