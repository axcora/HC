### Installation Guide

#### What You Need

Before installing RentCar, you need two things.

**Node.js**

Download from https://nodejs.org

Choose the **LTS version**. Install it. Restart your computer after installation.

**VS Code**

Download from https://code.visualstudio.com

Choose your operating system. Install it. Keep default settings.

#### Step 1: Extract the ZIP File

Extract the downloaded ZIP file to a folder on your computer.

Example:

- Windows: `C:\Users\YourName\Projects\rentcar`
- Mac: `/Users/YourName/Projects/rentcar`

#### Step 2: Open the Folder in VS Code

1. Open VS Code
2. Click **File** → **Open Folder**
3. Select the `rentcar` folder
4. Click **Select Folder**

#### Step 3: Open Terminal in VS Code

1. Click **Terminal** in the top menu
2. Click **New Terminal**

A terminal panel opens at the bottom.

Open your browser. Go to:


Your website is now running.

### Configuration

#### Step 1: Open gatsby-config.js

In VS Code, open the file:

```
gatsby-config.js
```

You will see this section at the top:

```js
siteMetadata: {
  title: `RentCar - Car Rental Theme`,
  titleTemplate: `%s | RentCar`,
  gst: ``,
  author: {
    name: `Your Name`,
    summary: `Modern car rental website with direct email booking and Decap CMS.`,
  },
  description: `Modern car rental website with direct email booking and Decap CMS.`,
  siteUrl: `https://yourdomain.com/`,
  social: {
    twitter: ``,
    facebook: ``,
  },
  keywords: [
    `car rental website`,
    `car rental theme`,
    `jamstack car rental`,
    `decap cms theme`,
    `direct booking car rental`,
  ],
},
```

#### Step 2: Change These Fields

**title**

Change to your website name.

Example:

```js
title: `My Car Rental`,
```

**description**

Change to your website description.

Example:

```js
description: `Premium car rental service in your city.`,
```

**siteUrl**

Change to your website URL.

Example:

```js
siteUrl: `https://mycarrental.com/`,
```

**author.name**

Change to your name or company name.

Example:

```js
author: {
  name: `My Car Rental`,
  ...
},
```

#### Step 3: Change Site URL in Plugins

Scroll down in `gatsby-config.js`. Find these two sections:

```js
{
  resolve: `gatsby-plugin-robots-txt`,
  options: {
    host: `https://yourdomain.com`,
    sitemap: `https://yourdomain.com/sitemap-index.xml`,
    policy: [{ userAgent: `*`, allow: `/` }],
  },
},
{
  resolve: `gatsby-plugin-canonical-urls`,
  options: {
    siteUrl: `https://yourdomain.com`,
  },
},
```

Change `https://yourdomain.com` to your actual domain.

#### Step 4: Save and Restart

1. Save the file (`Ctrl + S` or `Cmd + S`)
2. In terminal, press `Ctrl + C` to stop the server
3. Type `npm start` to restart

### Decap CMS Setup

#### Important: Development vs Production

Gatsby `develop` server does not serve the `/admin/` path. To use Decap CMS locally, you must run `build` and `serve`.

- `npm start` — CMS returns 404
- `npm run build` + `npm run serve` — CMS works

#### Step 1: Open Two Terminals

1. Open VS Code
2. Click Terminal → New Terminal
3. Click the + icon to create a second terminal

#### Step 2: Build and Serve in Terminal 1

In Terminal 1, type:

```
npm run build
```

Wait until build completes. Then type:

```
npm run serve
```

Wait until you see:

```
You can now view rentcar in the browser.

  http://localhost:9000/
```

Leave this terminal running.

#### Step 3: Start Decap CMS Proxy in Terminal 2

In Terminal 2, type:

```
npx decap-server
```

Wait until you see:

```
Decap CMS Proxy Server listening on port 8081
```

Leave this terminal running.

#### Step 4: Access the CMS

Open your browser. Go to:

```
http://localhost:9000/admin/
```

You will see the Decap CMS login page. In local mode, no login required.

### Deployment

#### Step 1: Create GitHub Account

If you do not have a GitHub account, create one at:


#### Step 2: Create a New Repository

1. Log in to GitHub
2. Click the + icon in the top right

4. Enter repository name: `rentcar`
5. Select Private or Public
6. Leave all checkboxes unchecked

#### Step 3: Push Your Code to GitHub

Open VS Code with your project folder. Open terminal.

```
git init
```

```
git add .
```

```
git commit -m "Initial commit"
```

```
git branch -M main
```

```
git remote add origin https://github.com/your-username/rentcar.git
```

```
git push -u origin main
```

Replace `your-username` with your GitHub username.

#### Step 4: Deploy to Netlify

1. Go to https://www.netlify.com
2. Click Sign up → Sign up with GitHub
3. Authorize Netlify
4. Click Add new site → Import an existing project
5. Click Deploy with GitHub
6. Select your `rentcar` repository
7. Configure build settings:

Build command: `npm run build`

Publish directory: `public`

8. Click Deploy site

#### Step 5: Add Custom Domain

1. In Netlify dashboard, go to Domain management
2. Click Add domain → Add a domain you already own
3. Enter your domain name
4. Click Verify → Add domain

Netlify will show you the DNS records you need to configure at your domain registrar.

#### Step 6: Configure DNS at Your Registrar

Log in to your domain registrar (Namecheap, GoDaddy, Cloudflare, etc).

For apex domain (yourdomain.com): Add an A record pointing to Netlify's load balancer IP.

For subdomain (www.yourdomain.com): Add a CNAME record pointing to your Netlify subdomain.

Example:

```
www  CNAME  your-site-name.netlify.app
```

#### Step 7: Enable HTTPS

1. In Netlify dashboard, go to Domain management → HTTPS
2. Click Verify DNS configuration
3. Click Provision certificate

Netlify automatically provisions a free Let's Encrypt SSL certificate.

#### Step 8: Automatic Deployments

Every time you push changes to GitHub, Netlify rebuilds your site automatically.

```
git add .
git commit -m "Update content"
git push
```

Wait 1 to 3 minutes. Your changes go live.

#### Optional: Deploy to Vercel

1. Go to https://vercel.com
2. Click Sign up → Continue with GitHub
3. Click Add New → Project
4. Select your `rentcar` repository
5. Framework Preset: Gatsby
6. Click Deploy

For custom domain:

1. Go to Settings → Domains
2. Enter your domain
3. Add A record (apex) or CNAME record (subdomain) at your registrar
4. Vercel provisions SSL automatically

### Support

#### Before Contacting Support

#### Common Issues

**Images Not Loading**

Check that image paths in JSON files and Markdown frontmatter match actual file locations.

All images should be in `static/images/`. Use `/images/filename.webp` in your content files.

**Build Fails on Netlify**

Add an environment variable in Netlify:

Key: `NODE_VERSION`

Value: `18` or `20`

Then trigger a new deploy.

**CMS Login Not Working**

Check that:

1. Netlify Identity is enabled
2. Git Gateway is enabled
3. The `branch` in `config.yml` matches your default branch

**Port Already in Use**

```
npm start -- --port 8001
```

**/admin/ Returns 404 in Development**

This is expected. Gatsby `develop` server does not serve static HTML files.

Use `npm run build` and `npm run serve` instead. Access CMS at `http://localhost:9000/admin/`.
