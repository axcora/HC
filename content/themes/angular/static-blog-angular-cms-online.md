This project you will be learn how to develope [angular](https://angular.io) blog project with [stackblitz](https://stackblitz.com) online IDE and integration with google [firebase](https://firebase.google.com) host.

### Documentation

+ Download source code project
+ Create github account
+ Register on Stackblitz with your github account
+ Upload this source code in to your stackblitz project
+ Create firebase account
+ Integration your stackblitz with firebase console
+ Deploy your project from stackblitz in to firebase host
+ Update content blog in to src/app/blogs.ts
