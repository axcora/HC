## Frequently Asked Questions

### What is Tailwind Blog, and what problem does it solve?

Tailwind Blog is a premium Bludit template built with Tailwind CSS for minimalist blogs. Bludit is a flat-file CMS: posts and pages are stored as JSON text files, so there is no database to install or configure. The template ships with a clean minimalist Tailwind design, automatic SEO (meta tags, Open Graph, Twitter Card), support for multiple plugins, and responsive utility-first output. Instead of setting up a CMS, a database, a theme, and SEO plugins from scratch, you upload the installer, run it, and the site is live.

### Do I need a database or coding skills to use Tailwind Blog?

No. Bludit stores content as flat files, so there is no database and no SQL to manage. Installation is upload, run, and the site is live. Daily work happens in the Bludit admin panel at `/admin`: settings, users, plugins, categories, content, and the custom fields that drive the landing page design. You do not need to code to run the site.

### How do I install Tailwind Blog?

Download the full source code, upload it to your hosting, visit your site, and run the installation. The default user is `admin`, but you can change it later. Insert a password, click install, and the site is live. Bludit deploys easily on cPanel, Plesk, or other shared hosting. The installer is light and does not take much hosting space. To log in to the backend, visit `yourwebsite.com/admin`, enter `admin` and your installer password, and you land on the dashboard.

### How do I secure the admin account and configure the site?

For security, open the Users menu in the sidebar, create a new user with the admin role and a password, and save. Then delete the default admin user, so the site runs on your new account. Next, open Settings → General and insert your title, description, and slogan. Use the tab menu to update the site, and click the Logo tab to upload your logo. Then create the custom fields needed for the landing page, following the documentation.

### Which plugins do I need to activate?

Open the Plugins menu and activate Sitemap, RSS, Twitter Card, and Open Graph. With these active, the site generates a sitemap and an RSS feed automatically and outputs Twitter Card and Open Graph tags for social sharing. Combined with the template's auto SEO injection (meta tags, Open Graph, Twitter Card), the site is ready for search engines without manual meta wiring.

### How do I create a blog post or a static page?

Open Manage → Categories and create or edit the categories that group your content. Then click New Content, insert the title, and write the article. Open the Options button on the article form → General, insert the description, upload the cover image, and select the group category. Open the Advanced tab to add tags. In the Type section, choose Default for a blog post, Static for a page, or Sticky for a landing page. Save to apply.

### What is the Sticky post and Custom tab, and how do I build a landing page?

The Sticky type turns a post into the homepage landing page, and the Custom tab is the landing page builder. To build a landing page, create a content article with Type Sticky, open the Custom tab, and fill in the text and image URLs for each homepage section. Save to apply. You can build multiple landing pages this way, or combine a blog format with a landing page by making one post sticky. For regular blog posts, leave the Custom tab empty; it is only used for landing page design.

### Can I use Tailwind Blog for client projects, and what is the license?

Yes. The license is a one-time purchase and you own 100% of the source, so you can use it on personal and client projects without recurring fees. The license does not permit reselling or redistributing the theme itself as a competing product. If you need a fully custom build, custom work is available through the Fiverr link in the theme listing.

### How is Tailwind Blog different from Darkco, Creative Agency, and Bludic Pro?

All four are Bludit flat-file CMS templates from the same lab, but they target different needs. Tailwind Blog is the minimalist Tailwind CSS blog with a Sticky post landing page builder. Darkco is the dark modern blog with a clean minimalist layout. Creative Agency is the creative agency and startup template with portfolio and landing sections. Bludic Pro is the Ionic mobile web app UI with PWA support and hidden plugins for categories, blogs, tags, and gallery. Choose based on the design direction and the features you need.
