### Installation

Download and Install Node JS

Now we need to install superstatic so open terminal and run this command on source code project folder : 

`npm i superstatic`

Next you can run superstatic by double click on superstatic.cmd file then you can see on shell terminal displaying port , so you can visit port terminal with visit localhost:yourport on web browser.

For update content , you can open on js folder, then edit all files with code editor.

### Deploy
