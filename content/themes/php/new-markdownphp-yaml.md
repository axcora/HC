MARKDOWNUTS is an open-source project that revolutionizes web development by seamlessly integrating Markdown and YAML with PHP. This innovative solution offers:

Blazing-fast performance without the need for a database

Simple and intuitive content creation using Markdown

Flexible configuration options with YAML

Easy deployment and maintenance

Lightweight and efficient codebase

Perfect for developers seeking a streamlined approach to building static websites, MARKDOWNUTS combines the simplicity of Markdown with the power of PHP. Whether you're creating a blog, documentation site, or portfolio, MARKDOWNUTS provides the tools you need to build responsive and SEO-friendly websites quickly.

### Installation

You can use composer or donwload source code project.

#### Installation with composer

for composer installation you can run

```
composer create-project creativitas/markdownuts
```

### Installation with git

If you want you can also install with git, open your terminal and run

```
git clone https://github.com/mesinkasir/markdownuts.git
```

Now you can open your project, or use terminal `cd yourproject`

Next you can run `composer install`

and access your site.

#### Installation with source code full

If you want you can use main source code, [Download Main Source Code](https://creativitaz.gumroad.com/l/markdownuts-starter)

Download main source code and upload in to your project folder, or into your hosting.

### Content Article

Markdownuts is use static site generator concept, so you can access on `pages` if you want to create new static pages and access your `posts` if you want write new blog article post.

#### Static Page

To create new article page you can simply create new markdown file same like how we work with jekyll or eleventy. if you want to delete article just delete your markdown file, for update you can open your article and update it.

Static page frontmatter format :

```
---
title: Your Staitc Page Title
description: Description about your static page
---
Write article in here....
```
