### Installation :

+ Download Node JS
+ Download Ruby Rails
+ Download Source Code Project
Run installation 

`bundle install`

Run Command 

`rails webpacker:install`

Now we need to seed database , run this command 

`rails db:migrate`

Next , you can run on local with this command 

`rails s`

And open `localhost:3000`
