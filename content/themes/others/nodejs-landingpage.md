### Documentation

+ Download Node JS NPM

+ Download Source Code

+ Create Project folder

+ Extract and move all source code files in to your project folder

+ Run Installation npm install

+ Run Express install npm install express --save

+ Run Project node app.js

+ Open localhost:3000


### Run on Hosting

+ Create Node App on your hosting
+ Upload Source Code Project
+ Run node app.js
+ Restart your node app
