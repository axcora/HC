### Documentation

+ Download Composer
+ Download [Laravel](https://laravel.com/) CLI
+ Download Source Code Project
+ Extract source code in to your project
+ Run Installation composer install
+ Run Key Generate `php artisan key:generate`
+ Run Project `php artisan serve`
+ Open localhost:8000
+ For backend login in to /admin
+ Login default with user:admin@admin.com / pass: 12345678
