<p>NUXAS + Decap CMS is a Nuxt 4 frontend theme for SaaS founders, agencies, and freelancers who need a fast, SEO-ready marketing site <strong>and</strong> a browser-based dashboard for editing content. No terminal, no Git commands, no code editor for daily updates.</p><p>This edition includes everything in the Code Only edition, plus a fully integrated <strong>Decap CMS</strong> setup. You (or your client) log in at <code>/admin</code>, edit blog posts, products, and site settings, and the CMS commits changes to your Git repository automatically.</p><p>Layout is separated from content. Pages read from Markdown and YAML files. SEO meta is generated from page data. The CMS edits those files, not the components. The result: non-developers can update copy, images, and pricing without breaking the design.</p><p><strong>COMPARE EDITIONS</strong></p><p>This is the Code + Decap CMS edition.
